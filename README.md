# Linkedin Cover Generator
A React-based tool that generates professional LinkedIn cover banners using random images.  
It automatically fetches photos from Unsplash, overlays your personal information (name, title, email, etc.), and produces a clean cover design you can use directly on your LinkedIn profile.

---

##  Features
- Auto-fetches fresh photos from Unsplash (new photo every 10 seconds).
- Click image to instantly fetch another photo.
- Customizable personal details (name, title, email, etc.).
- Stylish overlay with modern typography and colors.
- Responsive design for LinkedIn banner dimensions (1584×396 px).

---

## Project Setup

### 1. Clone the repository
```bash
git clone https://github.com/0xrootAnon/linkedin-cover-generator.git
cd linkedin-cover-generator
```

### 2. Install the dependencies and run the project
```
npm install
npm run dev
```

Note that using Webpack is obselete and this archive has been provided
for compatibility reasons. Prefer using Vite, check it at https://vitejs.dev
